# XMLity NS XML

Generated Rust bindings for the XML namespace (http://www.w3.org/XML/1998/namespace). This crate provides type-safe access to standard XML attributes and elements defined in the XML specification.

## Features

- Complete bindings for XML namespace attributes (xml:lang, xml:space, xml:base, xml:id)
- Type-safe attribute value handling
- Integration with XMLity serialization framework

## Namespace

This crate represents the `http://www.w3.org/XML/1998/namespace` namespace, providing access to the fundamental XML attributes that can be used in any XML document.
