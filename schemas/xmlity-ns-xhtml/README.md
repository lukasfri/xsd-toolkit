# XMLity NS XHTML

Generated Rust bindings for XHTML 1.0 Strict namespace. This crate provides comprehensive type-safe access to all XHTML elements and attributes as defined in the XHTML 1.0 Strict specification.

## Features

- Complete XHTML 1.0 Strict element bindings (html, head, body, div, p, etc.)
- Type-safe attribute handling for all XHTML attributes
- Integration with XMLity serialization framework
- Support for XHTML document structure validation

## Namespace

This crate represents the XHTML namespace, providing structured access to XHTML elements for building and parsing XHTML documents with compile-time type safety.
