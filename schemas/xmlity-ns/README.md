# XMLity NS

Core namespace utilities and common functionality for XML namespace handling in XMLity-generated code. This crate provides foundational components used across generated schema bindings.

## Features

- Substitution group support for XML Schema element substitution
- Generic list type implementations for XML Schema list types
- XML attribute handling utilities
- Common utility functions for generated code

## Usage

This crate serves as a dependency for other XMLity namespace crates, providing shared functionality and utilities that are commonly needed across different XML Schema namespace bindings.
