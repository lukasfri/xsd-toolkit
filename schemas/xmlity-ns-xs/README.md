# XMLity NS XS

Generated Rust bindings for the XML Schema namespace (http://www.w3.org/2001/XMLSchema). This crate provides comprehensive type-safe access to all XML Schema elements, types, and attributes as defined in the W3C XML Schema specification.

## Features

- Complete XML Schema element bindings (schema, element, complexType, simpleType, etc.)
- All XML Schema built-in types and facets
- Custom extensions for improved usability
- Integration with XMLity serialization framework

## Namespace

This crate represents the `http://www.w3.org/2001/XMLSchema` namespace, providing the foundational types needed to work with XSD schema documents programmatically.
