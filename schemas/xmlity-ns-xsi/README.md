# XMLity NS XSI

Generated Rust bindings for the XML Schema Instance namespace (http://www.w3.org/2001/XMLSchema-instance). This crate provides type-safe access to XSI attributes used in XML instance documents for schema validation and type specification.

## Features

- XSI attribute bindings (xsi:type, xsi:nil, xsi:schemaLocation, xsi:noNamespaceSchemaLocation)
- Type-safe handling of schema instance information
- Integration with XMLity serialization framework

## Namespace

This crate represents the `http://www.w3.org/2001/XMLSchema-instance` namespace, providing access to attributes that control schema validation and type information in XML instance documents.
