# XSD Builtin

Implementation of XML Schema built-in types and facet constraints. This crate provides Rust representations of the standard XSD primitive types, derived types, and their associated validation facets as defined in the XML Schema specification.

## Features

- XML Schema primitive types (string, decimal, boolean, etc.)
- Built-in derived types with proper inheritance hierarchy
- Facet implementations for value space restrictions
- Type-safe representations of XSD built-in functionality

## Types

This crate implements the complete set of XML Schema built-in types as specified in W3C XML Schema Definition Language (XSD) 1.1, providing the foundation for type validation and code generation in other toolkit components.
