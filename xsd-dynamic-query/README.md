# XSD Dynamic Query

Runtime query system for XSD schema fragments enabling dynamic inspection and traversal of compiled schema structures. This crate provides APIs for programmatically examining type definitions, relationships, and constraints within processed XSD schemas.

## Features

- Dynamic querying of complex and simple type fragments
- Runtime type identification and classification
- Schema traversal utilities for finding related types
- Integration with fragment-based schema representation
- Support for namespace-aware queries

## Usage

This crate enables runtime analysis of XSD schemas that have been processed through the fragment compilation pipeline. It provides essential functionality for tools that need to inspect schema structures programmatically, such as validation frameworks or schema analysis utilities.
